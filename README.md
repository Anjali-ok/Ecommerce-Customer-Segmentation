# 🛒 E-Commerce Customer Segmentation & Purchase Behavior Analysis

An end-to-end data science project that analyzes e-commerce customer purchasing behavior using **RFM Analysis, K-Means Clustering, PCA, and an interactive Streamlit dashboard**.

The project transforms raw transaction data into meaningful customer segments and business insights that can support customer retention, targeting, and revenue analysis.

---

## 📊 Project Overview

This project analyzes customer transactions from an online retail dataset.

The workflow includes:

- Data exploration
- Data cleaning
- Exploratory Data Analysis (EDA)
- Revenue analysis
- Customer-level RFM analysis
- Customer segmentation using K-Means
- PCA visualization
- Interactive Streamlit dashboard
- Business insights and recommendations

---

## 🎯 Objectives

The main objectives of this project are:

1. Understand overall e-commerce sales performance.
2. Identify important revenue and product trends.
3. Analyze customer purchasing behavior.
4. Calculate customer Recency, Frequency, and Monetary value.
5. Segment customers based on purchasing behavior.
6. Visualize customer segments.
7. Build an interactive dashboard for business analysis.

---

## 🗂️ Dataset

The project uses the **UCI Online Retail Dataset**.

The dataset contains transactional records from an online retail store.

Important columns include:

| Column | Description |
|---|---|
| InvoiceNo | Transaction / invoice number |
| StockCode | Product code |
| Description | Product description |
| Quantity | Number of products purchased |
| InvoiceDate | Date and time of transaction |
| UnitPrice | Price per product |
| CustomerID | Unique customer identifier |
| Country | Customer's country |

The raw dataset is not included in the GitHub repository.
